Ubuntu System Monitor & Automation 🚀

Проект представляет собой легковесный инструмент для мониторинга состояния системы и автоматизации базовых задач администрирования в среде Ubuntu. Основная логика упакована в Docker-контейнер для обеспечения переносимости и изоляции.

📋 Основные функции

Мониторинг ресурсов: Скрипт sys_stat.sh собирает данные о текущей дате, активных пользователях (с их IP-адресами) и аптайме сервера.
Контейнеризация: Проект полностью готов к запуску через Docker, что исключает конфликты зависимостей на хостовой системе.
Логирование: Все отчеты мониторинга автоматически отправляются в системный журнал сервера (logger).
Автоматизация пользователей: Набор скриптов для быстрого создания новых пользователей с генерацией надежных паролей и правами sudo.
🛠 Технологический стек

Bash: Основной язык сценариев.
Docker: Среда для запуска изолированного мониторинга.
Linux Utils: Использование awk, sed, procps и coreutils для обработки данных.
📂 Структура проекта

ubuntu-monitor/
Dockerfile: Описание образа для сборки контейнера мониторинга.
sys_stat.sh: Скрипт сбора системных метрик.
user/
create_users.sh: Скрипт автоматизированного создания пользователей.
setup.sh: Скрипт для первичного обновления системы.
.gitignore: Исключает логи мониторинга из репозитория.
